# Example: Solid + TanStack Form (parked)

> **This example is currently parked.** `@tanstack/solid-form` supports
> Solid 1 only (peer `solid-js ^1.6.0`, no Solid 2 release line), while
> `@tanstack/solid-table` on this branch targets Solid 2. The example is
> excluded from the pnpm workspace (see the negation in
> `pnpm-workspace.yaml`), so it is not installed, built, or tested — the
> source stays in-tree and will be un-parked once solid-form ships Solid 2
> support.

To run it in the meantime, copy the directory out of the repo and install its
dependencies standalone.
